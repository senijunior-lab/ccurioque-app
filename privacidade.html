Política de Privacidade

Seus dados ficam sob seu controle.

Esta política descreve o tratamento de dados pelo aplicativo pessoal Ccurioque Automacao Local e por este site informativo.

Finalidade e dados acessados

O aplicativo é destinado ao responsável pelo canal Ccurioque. Usa youtube.readonly para consultar o canal e o estado de seus vídeos. O módulo de publicação também solicita youtube.upload para enviar os vídeos autorizados, títulos, descrições, declarações de público/conteúdo e horários de publicação. A consulta atual solicita o identificador e os dados básicos do canal, incluindo seu nome, e verifica se correspondem ao canal esperado. Não consulta mensagens, dados financeiros ou informações de outros serviços Google.

Autorização e armazenamento

A senha da conta Google é tratada exclusivamente pelo Google. O aplicativo recebe tokens de acesso e renovação via OAuth e os armazena localmente, cifrados com a proteção DPAPI do usuário do Windows. O ID, nome, estado da conexão e data da última verificação ficam em arquivos locais de controle. Os arquivos originais e o histórico permanecem no computador. Quando a publicação é executada, os vídeos e metadados autorizados são enviados ao YouTube. URLs de sessões de envio também ficam cifradas localmente; os registros de execução guardam IDs, hashes e horários sem tokens.

Uso e compartilhamento

Os dados obtidos por meio das APIs Google são usados somente para fornecer as funções declaradas de consulta, conexão local, envio e agendamento de vídeos. Não são vendidos, usados para publicidade, transferidos a terceiros para outras finalidades ou usados para treinar modelos de inteligência artificial. O aplicativo se comunica com o Google para autenticação, renovação de tokens, consultas, envio e agendamento pela API do YouTube.

O uso e a transferência de informações recebidas das APIs Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Retenção, revogação e exclusão

As credenciais e os registros locais permanecem até que o proprietário os remova do computador. A publicação pode ser interrompida na automação local; vídeos já enviados e agendados devem ser gerenciados no YouTube Studio. O acesso pode ser revogado a qualquer momento na página de conexões da Conta Google. Para remover os dados locais, o proprietário pode excluir os arquivos de credenciais e registros da instalação. Revogar o acesso no Google não apaga automaticamente os arquivos locais; remover arquivos locais não substitui a revogação no Google.

Este site

Este site não contém formulários, rastreadores de audiência, cookies próprios ou scripts de publicidade. A hospedagem no GitHub Pages pode processar registros técnicos de acesso conforme a Política de Privacidade do GitHub. Links externos seguem as políticas dos respectivos serviços.

Contato e alterações

O responsável pelo aplicativo pode ser contatado pelo perfil senijunior-lab no GitHub. Alterações nas funções ou no tratamento de dados serão refletidas nesta política antes de sua adoção.
